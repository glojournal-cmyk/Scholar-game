====================================
Build date: 2026-09-12

IMPORTANT
- This RF8 package fixes the folder-flattening problem.
- NEVER upload a ZIP file itself into the repository.
- Download a batch ZIP, unzip it on your computer, then drag the CONTENTS into the repository root.
- Keep nested folders nested. In particular:
    assets/rf8/
    cp-y8/runtime/
    cp-y8/shared/
- Do not move files from those folders to the root.

RECOMMENDED CLEAN RE-UPLOAD
1. Keep a backup of your current repository.
2. Remove the old deployed app files from the branch used by GitHub Pages, or replace them with this RF8 tree.
   If you leave old unreferenced RF6/RF7 files behind, RF8 will still use its own paths, but a clean tree is safer.
3. Upload RF8_Web_Batch_01_of_15.zip CONTENTS and commit.
4. Repeat Batch 02 through Batch 15 in numerical order.
5. You do NOT need to wait for GitHub Pages to become green after each batch.
6. After Batch 15 is committed, wait for the newest Pages deployment to show Success/green.
7. Hard refresh the live page. If a service worker was previously installed, close/reopen the tab once after the new deploy.
